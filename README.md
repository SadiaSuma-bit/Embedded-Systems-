Smart Home System – Project Plan

Overview

We plan to make a simple smart home system using Raspberry Pi Pico W. It will monitor the room and automatically control some devices.

Main Functions

Smart light – LDR detects darkness and turns the light ON.

Temperature control – DHT22 measures temperature and turns the fan ON when it is hot.

Security – PIR detects motion and activates a buzzer in security mode.

Door monitoring – Pushbutton is used to simulate door opening.

Distance monitoring – Ultrasonic sensor measures the distance of a person or object near the entrance.

OLED display – Shows basic sensor and system information.

Remote alert – Pico W sends an alert through Wi-Fi/Discord when an important event happens.

Hardware

Raspberry Pi Pico W, DHT22, LDR, PIR sensor, ultrasonic sensor, pushbuttons, LEDs, buzzer, OLED display, resistors and wires.

Software

Wokwi, MicroPython and Discord Webhook.

Expected Output

The system will control the light and fan, detect motion and door activity, measure distance, show information on the OLED, sound an alarm, and send remote alerts.
